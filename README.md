# Bitmap Index Visualizer

An interactive web application designed to teach and demonstrate the mechanics of Bitmap Indexing through visualization, simulation, and AI-assisted explanations.

## Overview

This project serves as an educational laboratory for database systems, allowing users to:
- Generate mock datasets with configurable cardinality and distribution.
- Visualize how a bitmap index is constructed step-by-step.
- Simulate query execution (e.g., bitwise AND operations) to see how databases filter rows efficiently.
- Ask questions to an integrated AI Tutor for context-aware explanations.

## Tech Stack
- **Frontend:** Next.js (React), Tailwind CSS, Framer Motion
- **Database:** Prisma ORM
- **Language:** TypeScript
